# Code of Conduct

FieldMoist follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Contributors must provide a welcoming, harassment-free environment, use respectful technical discussion, and accept project-maintainer decisions made in the interest of the community.

Report unacceptable behavior privately to the project maintainers through the contact channel published by the repository owner. Maintainers will review reports promptly, protect the reporter's privacy where possible, and apply proportionate corrective action.
